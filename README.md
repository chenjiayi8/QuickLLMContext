
# QuickLLMContext

**QuickLLMContext** is a Chrome-based browser extension that enhances text selection with a quick-access popup menu. Easily configure and interact with multiple LLMs (e.g., GPT-4, Claude, Gemini) for instant context-aware AI assistance.

## 🚀 Features

* **Quick Popup Menu** – Access AI-powered tools instantly on text selection.
* **Multi-LLM Support** – Configure and switch between different AI models.
* **Customizable Options** – Tailor interactions to your workflow.
* **Works on Chrome, Edge, Brave, Opera, and other Chromium-based browsers.**

## 📦 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/chenjiayi8/QuickLLMContext.git
   cd QuickLLMContext
   ```
2. Open your Chrome-based browser and navigate to `chrome://extensions/`.
3. Enable **Developer Mode** (toggle in the top right corner).
4. Click **Load unpacked** and select the `QuickLLMContext` project folder.

## 🛠️ Usage

1. Select any text on a webpage.
2. A popup menu will appear with AI-powered options.
3. Choose an action to interact with your preferred LLM.
4. Configure LLM settings in the extension options page.

## ⚙️ Configuration

You can store and manage different LLM configurations using the  **extension options page** .

## 🏗️ Development

### Prerequisites

* **Node.js & npm** (optional, for additional dependencies)
* **VS Code** (recommended for development)

### Steps

1. Install dependencies (if needed):
   ```sh
   npm install
   ```
2. Modify `manifest.json` and `content.js` to extend functionality.
3. Reload the extension in `chrome://extensions/` after making changes.
